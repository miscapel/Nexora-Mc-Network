## 🎮 Game Modes
Nexora Network features diverse, highly optimized game modes tailored for every type of player:

- **Practice PvP** — Fast-paced duels, unranked/ranked queues, and custom arenas designed to test raw combat skills.
- **Battleground** — Action-packed competitive battles with custom mechanics, events, and dynamic scoring.
- **SMP (Survival Multiplayer)** — *Coming Soon!* A rich, community-driven survival experience featuring custom economy, land claiming, and polished progression systems.
